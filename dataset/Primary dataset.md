# LongMemEval Dataset

We use the LongMemEval-S cleaned dataset for our Agent Memory research project.

**Dataset source:** [LongMemEval-S Cleaned Dataset – Hugging Face](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned)

**Purpose:** This dataset will be used to evaluate conversational memory retrieval and question-answering performance in AI agents.

**Source:** Hugging Face – xiaowu0162/longmemeval-cleaned
