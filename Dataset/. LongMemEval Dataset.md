# LongMemEval Dataset

LongMemEval is a benchmark dataset designed to evaluate the long-term memory and information retrieval capabilities of Large Language Models (LLMs).
All the information about LongMemEval is available here: https://github.com/xiaowu0162/longmemeval

## Dataset Source

[LongMemEval – Hugging Face](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned)

## Purpose

Used to test how well AI agents remember, retrieve, and answer questions based on information from long conversations.

## Usage

Download the cleaned dataset from Hugging Face and use it for memory retrieval and evaluation experiments in the Agent Memory at Scale project.
